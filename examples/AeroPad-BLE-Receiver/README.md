# 单独 ESP32-S3 BLE-UART 接收端示例
此工程用于另一块 ESP32-S3，不是遥控器固件，不要烧录到 COM11 的遥控器。选择其真实端口后再烧录。
默认 UART1 RX=GPIO18，TX=GPIO17，8N1；接 3.3V UART 目标的 TX、RX、共地，按照实际接收板更改引脚。
接收端把 NUS 无线写入的原始控制数据转发到 UART1 和 USB CDC；UART1 收到的回显通过 NUS 通知返回遥控器。四种格式见主工程 docs/CONTROL_PROTOCOL.md；二进制20字节，JSON/HEX/文本均按换行拼接。
扩展参数特征6e400004-b5a3-f393-e0a9-e50e24dcca9e提供4字节小端实际UART波特率。写入后UART真实更新，再允许读回核对，并保存到NVS，支持9600/19200/38400/57600/115200。遥控器会自动识别此特征。普通模块不一定提供它。
默认发送50ms和二进制适合低波特率；JSON更长，低速UART应降低发送频率或使用二进制。队列溢出会累计dropped，不能将无线写入成功视为外接目标已执行命令。

示例在5000ms没有收到数据时清空待发送旧数据，向UART发送neutral归零帧；实际外接目标仍需要识别协议和独立失联保护。
