# 硬件、校准与操作

## 本工程引脚

|控件|GPIO/总线|
|---|---|
|LX / LY|GPIO2 / GPIO1|
|RX / RY|GPIO16 / GPIO15|
|左/右ADC旋钮|GPIO14 / GPIO3|
|电池电压采样|GPIO4|
|板载LED|GPIO38|
|板载左/右按键|GPIO0 / GPIO21|
|左前上/下按键|GPIO46 / GPIO39|
|右前上/下按键|GPIO45 / GPIO44|
|功能键与四路拨杆|MCP23017，详细管脚见 `src/controller_keys.h`|
|MPU6050 / MCP23017|I2C地址0x68 / 0x27|
|显示屏|RM67162 QSPI，见 `src/pins_config.h`|

蜂鸣器原定义GPIO16与右摇杆X冲突，本工程禁用蜂鸣器；确认独立接线后才可重新启用。接收端例子的GPIO17/18是另一块接收板的UART引脚，不能照接到遥控器上（遥控器显示也使用这些GPIO）。

摇杆和旋钮协议输出为-100～100，不是0～4095 ADC。校准分别采集中心、极限和旋钮两端；NVS保存，开机恢复有效参数。倾角AX/AY是控制量，±45°映射±100；MPU无磁力计，立方体航向是相对量。

## 进入与返回

|页面|操作|返回|
|---|---|---|
|主菜单|方向键选择，O进入|停留主菜单|
|一般子菜单|方向键或左摇杆选择，O进入|X返回上级|
|蓝牙游戏手柄|电脑配对后输入，按键保留HID用途|B+X同时返回|
|蓝牙模块列表|O连接，A重新搜索，B模块设置|X返回|
|模块控制中|所有控件发送v1数据；发送格式独立设置|B+X返回设备菜单并尝试发送释放帧|
|发送设置|上下选格式/间隔，左右调整，即改即存|X返回|
|串口设置|上下选本机/对方；本机左右选回显；对方O进入|X逐级返回|
|按键测试|每个按键/轴均用于测试|**同时按B+X**返回|
|控件校准|按页面引导完成采集与确认|X取消；有效微调自动保存|
|立方体|O归零，A暂停/继续，B静置校准|X返回|
|WiFi管理|O开关热点，A开机连接开关|X返回，热点继续保持|
|设备监测|左右切换六页|X返回|

菜单摇杆先回中，55%触发，回中25%重新准备，长推450ms后180ms重复。游戏独立操作见 [游戏玩法](LOCAL_GAMES.md)。

## HID输入与控制协议不同

HID六轴输出范围为-32767～32767。按钮1～14依次为A、B、X、O、左前上/下、右前上/下、板载左/右、左拨杆1/2、右拨杆1/2；方向键通过方向帽表示。v1协议则把方向键也编入位图，共18位；不要把HID按钮编号当成v1 bit编号。
