# 设备监测

系统设置 → 设备监测。左右方向键或左摇杆切换6页，X返回。每100ms读取一次统计，切页立即重画；固件大小只在进入页面时读取一次，避免反复校验Flash阻塞输入。不同数据采用不同颜色，底部说明白色。

1. 使用率：内部堆、外部PSRAM、运行固件分区占用、内部最大可分配块占空闲比例。前三项=已用/总量；第四项=最大块/空闲量，用于观察连续内存可用性，不能称为CPU使用率。
2. 内部内存：总堆、当前空闲、启动以来最低空闲、最大连续可分配块。
3. 外部PSRAM：总量、已用、空闲、最大可分配块。
4. 硬件与运行：CPU频率、物理Flash容量、任务数量、本次运行时间。
5. 无线网络：RSSI、信号估算百分比、热点客户端数、WiFi连接IP。质量百分比用RSSI -100到-50dBm映射到0到100，仅是估算；未连接显示--。
6. 蓝牙模块：逻辑发送帧数、接收字节数、写入错误次数、配置发送间隔。计数不是远端动作确认，不是蓝牙HID统计。

KiB=1024字节，MiB=1024KiB。固件占用以当前运行应用分区为分母，不能当作整个物理Flash使用率。内部堆统计也不代表ESP32所有硬件RAM。CPU频率不是CPU负载，本页没有伪造CPU使用百分比。
