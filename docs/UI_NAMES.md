# 网页自定义界面与预设名称

1. 遥控器进入「网络信息 → WiFi 管理」，按 O 开启热点。
2. 手机连接 `AeroPad-Setup`，密码 `12345678`。打开 `http://192.168.4.1/`。
3. 找到「界面与预设名称」，展开对应分类，输入中文或英文名称，点击该项「保存名称」。看到「已保存名称，重启后仍保留」才表示写入成功。
4. 返回遥控器菜单，选中长名称时，它会在原有标题/预设框内缓慢向左滚动；未选中时保持静止。短名称居中。

可改主菜单、NRF 无人机/四驱车/调试/设置、本机游戏、WiFi 管理、蓝牙功能入口、系统设置，以及无人机、四驱车、蓝牙遥控各自的预设 1～5。每项最多 32 个 Unicode 字符、128 字节，显示宽度最多 1024 像素。超出限制会显示错误，并保留原名称。

**名称与参数分别保存。** 给空槽位起名不会创建遥控协议；仍需在遥控器的预设页面保存实际参数。预设框右侧绿点表示已保存参数，灰点表示空槽。重命名不会改变应用槽位、无线地址、蓝牙实际广播名称、热点名称、安全状态或按键说明。

「恢复默认」只恢复该项标签。可导出 JSON 名称备份，也可导入已有备份；备份只包含名称，不包含 WiFi 密码或遥控协议。导入会逐项保存，网络中断时已经成功的项目保留；重新导入可完成剩余项目。

## 中文与存储

手机网页利用本地字体生成 28 像素中文字形，与名称一同上传。无需联网下载字体。字形使用 1 位图存入设备 SPIFFS，启动后在后台缓存到 PSRAM，所以离开网页、重启、掉电后仍能显示。不同手机的字体外观可能略有不同；重新保存同一个名称可更新字形。

每个名称使用两份记录、递增版本和 CRC 校验；新记录写入并回读校验成功后才替换当前显示。发生部分写入时保留旧有效记录。首次使用仅在确认整个文件系统分区为空时初始化，已有非空但无法挂载的分区不会自动格式化。首次初始化在后台进行，主菜单可以正常使用；网页会自动等待存储就绪。

## 刷新与性能

长名称仅在选中时进行动画，菜单以 33 ms 周期检查变化，仅把变化的 16 行屏幕区域传给显示屏。预设名称字形在 PSRAM 缓存，动画中不读取文件、不写 Flash、不动态分配字形内存。网络任务固定到 CPU0，与 CPU1 的界面任务分开；保持 WiFi 调制解调器休眠设置，避免破坏蓝牙共存。

处理器原本已运行在 240 MHz，本次没有超频。无线功能仍只在对应页面开启，退出后关闭；原有停车确认、失联和协议保护不受名称编辑影响。性能应以实际响应与刷新测试为准，不能由 CPU 标称频率推断实际车控链路可靠性。

## 验证范围

新增存储格式使用独立测试验证 UTF-8、长度限制、CRC 及损坏数据拒绝；网页使用手机宽度检查输入和按钮布局。设备端 HTTP 验证中文保存/读取、错误输入保持原值、恢复默认及重启持久化，并通过串口读取真实屏幕帧检查滚动边界。名称改动不会重新进行车辆运动试验。
