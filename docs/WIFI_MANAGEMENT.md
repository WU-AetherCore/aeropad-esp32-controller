# WiFi 管理

入口：网络信息 → WiFi 管理。方向键或左摇杆选择菜单，O进入。

- O：开启或关闭热点；X：返回。退出页面不关闭热点。
- A：切换“开机自动连接 WiFi”，屏幕显示开/关并自动保存；网页也可通过“开机连接设置”保存该选项。关闭只影响下次开机，不断开当前连接、不清除凭据。旧版配置默认开启。
- 热点名称：`AeroPad-Setup`，密码：`12345678`。
- 手机/电脑连接后通常会弹出登录网页；如果没有自动弹出，浏览器输入 `http://192.168.4.1/`。热点未接入互联网时，手机请选择保持连接。
- 网页搜索附近2.4 GHz WiFi，也可以手动输入名称。输入密码后点击保存并连接，下方实时状态显示连接结果。连接超时20秒后显示失败。
- 路由器名称、密码及开机连接开关保存到NVS，开关开启时重启自动尝试连接，关闭时不连接。热点默认关闭，由实体O键开启；配置路由器时已开启的热点保留。
- 连接路由器后，同一网络内可使用屏幕显示的路由器IP打开网页。
- 网页显示IP、信号、热点客户端数、MAC、运行时间、可用内存和PSRAM，以及双摇杆、双旋钮、按键位图和倾角。采样年龄用于识别停留在阻塞页面时的旧数据。
- 清除路由器配置需要网页确认，仅清除WiFi凭据，不清除摇杆校准和蓝牙设置。

控件数据通过独立轻量接口更新，每次响应完成后50ms发起下一次请求，不堆积并行请求；实际刷新率取决于无线延迟和设备采样。网络状态每2秒更新，扫描结果只在用户搜索后查询。后台浏览器页面降低刷新频率，网络超时自动重试。

搜索采用异步被动扫描，每频道120ms；5秒内防止重复扫描，连接路由器期间提示稍后重试。ESP32只有一个2.4GHz射频，扫描其他频道仍可能短暂延迟热点数据，不能保证所有手机永远不断线。配置路由器时热点会跟随路由器频道，手机可能需要重新连接。手机若提示热点无互联网，请选择保持连接。

网页只读控件数据，不向车辆/蓝牙发送控制指令。密码不通过状态接口返回。网页使用局域网HTTP，热点具有默认密码；仅让可信设备连接。自动弹窗依赖手机/电脑的网络探测，HTTPS网页无法被热点重定向。
